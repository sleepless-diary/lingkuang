# 灵框 LingKuang · 用户操作手册

阈限梦核世界观工作台：时间线 / 随机角色生成 / 词义联想图 / Markdown 编辑器。

---

## 1. 安装与启动

**普通用户**：从 [Releases](https://github.com/sleepless-diary/lingkuang/releases) 下载
- `LingKuang-x.x.x-x64.exe` — 安装版，双击安装
- `LingKuang-x.x.x-portable-x64.exe` — 便携版，双击即用

**开发者**：需 Node.js 18+，`npm install && npm start`

> 数据保存在系统 `%APPDATA%\lingkuang\`（时间线、设置、暂存词），卸载/换版本不丢失。

## 2. 界面总览

- **左侧导航栏**：工具 / 插件（世界观 · 设定库 · 灵感触发器）/ 系统
- **大厅**：插件卡片，点击进入各工具
- **AI 面板（The Hum）**：右下角呼吸灯，AI 对话入口（实验性）

## 3. 世界沙盘（时间线 + 地图）

### 浏览
| 操作 | 效果 |
|---|---|
| 拖拽空白 | 平移画布 |
| 滚轮 | 横向移动 |
| **Alt + 滚轮** | 缩放（以鼠标为中心） |
| Alt + 右键拖 | 快速缩放 |
| 右键 | 节点/画布菜单 |
| 点节点 | 右侧详情面板（标题/时间/描述/标签/关联人物地点） |

### 节点操作
- **添加**：右键空白 → 「添加节点」→ 填时间/类型/标题/描述
- **编辑**：点节点 → 右侧面板改内容
- **删除**：右键节点 → 「删除节点」
- **类型**：世界事件 / 剧情·人物 / 年代锚点 / 循环边界

### 多时间线
- 顶部 tabs 切换；「＋」新建时间线
- 「并列」：并排显示所有时间线（对齐时间轴）；「序列」：事件等距视图

### 循环（轮回）
- 右键 →「创建循环」→ 面板吸管吸取**起始/结束边界节点**（或填年份自动建）
- 循环次数 `count` 可设多轮——重复轮次自动渲染为**实节点**（内容与第一轮同步）
- 循环框可点选，右侧面板改循环名/起止/次数/删除
- 共享边界：起始年与已有循环结束年一致时自动复用为共享边界（菱形 + 黄环）

### 剧情范围（AE 工作区式）⭐
聚焦"故事发生的区间"，范围外的世界历史被裁剪：

1. **创建**：右键 →「创建剧情范围」→ 面板里点「◉ 吸取起始节点」→ 面板收起，鼠标变十字 → 点时间线上的节点 → 面板弹回显示已选 → 同样选**结束节点** → 命名 →「创建范围」
2. **聚焦**：创建后自动聚焦该范围——时间线只显示范围内的节点，世界历史裁掉；顶部荧光绿色带标注剧情区间
3. **切换**：
   - tl-manager「剧情」按钮：聚焦 ↔ 世界历史（全显示）
   - 下拉：多个范围间切换 / 「世界历史」
4. 一条时间线可建**多个剧情范围**（如"第一章""第二章"），它们同属一条时间线

### 多世界观
- 顶部世界观按钮 → 切换/新建世界观（互不干扰，各自独立时间线）

## 4. 灵感触发器（随机角色生成）

1. 进入「灵感触发器」→ 点「随机生成」
2. 每组卡片右上角 **select**：词条数（随机 / 1..4）
3. **锁定**：点词条右侧 `⚿` → 下次随机保留该词（绿色实底）
4. **保存组合**：输入名字 →「保存」→ 变成胶囊；点胶囊加载、× 删除
5. **词义联想入口**：点任意词条 → 底部联想图以该词展开

### 暂存与导出（扩充词库）
- 联想图里**虚线词**（未入库）点「存」暂存；**实线词**已在词库无需存
- 攒几个后点「**导出暂存词**」→ Ollama 自动分类 → 写入词库（之后生成/联想能抽到）

## 5. 词义联想图

**打开**：灵感触发器页点任意词条，或在联想图顶部输入框输词点「联想」。

| 操作 | 效果 |
|---|---|
| 点词（未展开） | 展开它的一级联想（5 个直接相关词，本地/API LLM 生成） |
| 再点焦点词 | 刷新它的联想（保留已选支线） |
| 点虚线词「存」 | 暂存到词库（导出时写入） |
| 拖动节点 | 子树跟随（组内力导向，与外部断开） |
| 拖拽空白 | 平移画布 |
| Alt + 滚轮 | 缩放画布 |
| 点「导出暂存词」 | 批量分类并写入词库 |

**选中支线**：点过的词变成**描边绿**（保留支线）——刷新/收起都不丢；**实底绿** = 已暂存。

### AI 引擎配置（设置 → 模型）

设置面板左边是四个页签（**模型 / 画布 / 转场 / 演变**），AI 这些都归「模型」页。

**先说「供应商」**（2026-09-26 起）：一家供应商 = 一个端点 + 一把 Key + 一个模型。出厂只有一条
**本地 Ollama**，想要别家点「＋ 添加供应商」：

| 预设 | 端点 | 成本 |
|---|---|---|
| 本地 Ollama | `http://localhost:11434`（装好 Ollama 并 `ollama pull qwen2.5:7b`） | 免费（自付电费） |
| DeepSeek | `https://api.deepseek.com/v1` | 按量付费 |
| OpenAI | `https://api.openai.com/v1` | 按量付费 |
| 硅基流动 | `https://api.siliconflow.cn/v1` | 按量付费（常有免费额度） |
| 自定义供应商 | 自己填名字 / 端点 / Key / 模型（任何 OpenAI 兼容端点都行） | 看那家 |

预设只是**帮你把端点填好**：Key 与模型还得自己填。一行上的小圆点告诉你这家配好了没（本地 Ollama 不需要 Key）。
点一行右边的「使用」= 把它设为**当前在用** —— 灵框所有 AI 功能（联想 / 助手 / 角色扮演 / 酒馆 / 工作台）都走这一家。
改完点底下的「保存设置」生效。

**模型不用手打了**（2026-09-26 起）：在编辑卡里点「模型」那一栏会展开一份**清单** —— 它是去问这一家的端点要的
（原生 Ollama 问 `/api/tags`，OpenAI 兼容问 `/models`，所以「3B · Q4_K_M · 1.8 GB」那种小字是端点自己报的），
上面有搜索框、右边有「刷新」。点一行 = 选中它，再点「保存设置」落盘。

- **看不见想要的模型**：先点「刷新」；本机确实没装就先去 `ollama pull`。
- **端点没开 / Key 不对**：那行小字会写明原因（`拉取失败：连不上端点：…`），**清单不会消失**
  （显示上次拉到的那份），下面那行「或直接手填模型名」照旧能用 —— 探测只是给你候选，用哪个由你点。
- 改了 Base URL / API Key / 协议之后，小字会提示「端点改了 —— 点「刷新」重新问一次」。
- **老版本升上来的**：你原来填的 Base URL / Key / 模型会自动变成一条（自定义）供应商，不会丢。
- 代理 / 反代 / 局域网里的另一台机器：用「自定义供应商」填地址即可（例：`http://192.168.1.9:8000/v1`）。

未配置 AI 时，核心功能（时间线/生成/编辑器）完全可用，仅联想图不可用。

### AI 回复是怎么显示出来的（2026-09-26 起）

四个跟 AI 说话的地方（**助手 / 角色扮演 / 酒馆 / AI 工作台**）现在都这样：

- **边想边出字**（流式）：回复一个字一个字长出来，末尾有一根闪烁的光标；说完光标消失。
  不用再盯着"静着不动、然后啪地出现一大坨"。
- **markdown 会被渲染**：`**粗体**` → **粗体**、`` `代码` `` → 代码块、`#` 标题、`-` 列表、`>` 引用、
  ```` ``` ```` 围栏代码块、`[文字](链接)` 都会按格式显示，**不会再看到满屏的星号**。
  ⚠️ 模型万一吐 HTML，灵框一律当**文字**显示（不会被当标签跑起来）。
- **回答不再被灵框切短**（2026-09-26 修）：以前灵框给每次请求写死了输出上限（助手 900、角色扮演 400、
  酒馆 500……），长回答会被切在半句；现在**上限交给模型/端点自己定**（只有"就要短答案"的地方才限量：
  联想出词、会话起名、记忆总结）。如果**模型自己**到了输出上限，面板底部会写明
  「回复被模型的输出上限截断了」—— 说一句「接着说」它就能续下去。

- **模型的「思考」也看得见**（2026-09-26 起）：会思考的模型（DeepSeek 的推理模型、本地 qwen3 这类）
  想事情的那一段会在回答**上面**长出来（一边想一边长），回答一开始它就折叠成一行「思考 · N 字」——
  想回看点一下标题就展开。模型不吐思考（普通对话模型）时这一块**根本不出现**，不会留个空标题。
  ⚠️ 思考会跟这段对话一起存进 `agent/sessions.json`（一条最多留 4000 字），所以重开灵框还能翻回来看。
- **看不到思考？多半是模型不会思考**（2026-09-26 起）：普通对话模型（如本机的 `qwen2.5:7b`）的端点
  根本不回思考字段，界面上自然一个字都没有。这种情况助手会在底部**说明一次**并点名建议换模型
  （本地已装 `qwen3:14b` / `qwen3:32b` 都会思考，换过去立刻能看到）；同一次运行里只说一次，不吵人。

## 6. 设定库（工作台 · Markdown 编辑器）

> 「编辑器」工具已于 2026-09-13 并进**设定库**：**左栏是一棵文件夹树**
> （世界 → 时间线 → 种类 → 节点 ＋ 世界 → `_設定` → 类型 → 实体），跟硬盘上的目录一一对应，
> **打开就全部展开**（点某一枝收起）。没有别的形态、也没有筛选按钮 —— 要找哪一类就展开哪一枝。

- 左侧：**一个搜索框**（设定与事件一起搜，跨类别）+ **那棵树**
  —— 点左侧任意一行就编辑它（设定条目走中栏字段、时间线节点走属性面板 + 面包屑）
  - 树默认**全展开**；点「世界 / 时间线 / 种类 / `_設定` / 类型」这些行就是**收起／展开**那一枝
  - 没有节点的种类不列（硬盘上没这个文件夹）；实体类型**全部**列出来，空的置灰、展开会写一句「这个类型还没有实体」
- 中栏档案字段（模板决定有哪些字段）、右栏正文 = Markdown 所见即所得（失焦自动保存）
- 右上角那一组按钮**跟着你正在编的东西变**：
  - 编**设定条目**时：「类型 ▾ + 数量 + ＋新建实体」——**类型会跟着你正在编的那条走**（你改选别的类型，
    就以你选的为准，直到换条目）；**数量框**填 3 就是一次建 3 个，名字自动取唯一（新实体 / 新实体 2 / 新实体 3）
  - 编**时间线节点**时：「时间线 ▾ + 数量 + ＋新建节点」——**不用切去世界沙盘**，点一下就建一个（落在你选的那条时间线里，
    种类跟着你正在看的那个节点走），建完自动选中它（见 §3 世界沙盘时间线）
  - 刚建出来还没改名的条目在左树里是**绿色名字 + 一颗「待填」小药丸**（改过名就自动消失）——批量建完一眼看得出哪几条还没动
- 实体右边缘还有一条**演变**竖线（每个事件节点一版，见 §9）
- 编**时间线节点**时，中栏下方还有一块「**这件事改变了谁**」：这个事件改过哪些设定
  （名字 / 类型 / 第几版 / 改了什么），**点一行就跳到那条设定在这个事件之后的样子**
  —— 也就是"这件事发生之后，它长什么样"（`docs/BUGS.md` 第二十三轮）
- 正文上方两个小按钮：`H`（当前段落设为一级标题）／「插图」（把图片放进 vault 的 `assets` 并插到光标处）

## 7. 设置（左下角 ⚙ · **悬浮面板**）

点左栏最底下的「设置」，会浮出一层面板：**主区不动**（你正在编的条目、左栏展开的样子、滚动位置都留在后面），
改完点 × / Esc / 点面板外面就关掉。再点一次那个按钮也能关。

| 项 | 说明 |
|---|---|
| 缓动速度 / 缩放灵敏度 / 标尺密度 | 画布手感 |
| **模型** | 供应商（本地 Ollama / DeepSeek / OpenAI / 硅基流动 / 自定义）· 端点 · Key · **模型（点开是可选清单，见 §5）** |
| **设定演变** | 改动什么时候变成"一版"（手动 / 自动 / 锁定），详见 §9 |
| **换条目转场** | 在设定库里点另一条条目时的过渡：开关 / 速度 / 行与行错峰 / 入场距离。改完立刻生效，点一下左边的条目就能看出区别；关掉＝瞬间切换 |

## 8. 数据与备份

- 数据目录：`%APPDATA%\lingkuang\`（`worldbuilding.json` 时间线 + `settings.json` 设置 + 暂存词在 localStorage）
- 备份：直接复制该目录即可；恢复：放回原路径

## 9. 灵框助手（`Ctrl+K`）

- **呼出**：按 `Ctrl+K`（或点左栏「助手」按钮）→ 右侧滑出一栏对话；再按一次 / `Esc` / 点 × 关掉。它**不接管主区**，聊天时照样能编稿子。
- **平常是聊天，要用才给"手"**：面板顶上那排「**聊天 / Agent**」是模式开关，**每次打开都从「聊天」开始**（不会残留授权）。**两个模式都能动手**（用户 2026-09-26 改口：「聊天模式也留一点灵框内部的工具」）：区别只在**能连着走几步** ——「聊天」一次提问只做一个动作（做完就交回给你），「Agent」可以连着查、改、再查（最多 8 步），适合一次改一批的活。写入照旧受下面那行**权限两把旋钮**管（范围 × 要不要每次问）。关掉面板 = 回到「聊天」。**一次改一批**（给一批设定加同一个字段、一次建一串事件）是 **Agent 模式专属**：聊天模式收到这种"批量"请求时不会动数据，只会告诉你先切过去。
- **AI 页的「主会话」就是同一位助手**（2026-09-26 起，阶段 2C）：AI 工具左栏那条**主会话**与 `Ctrl+K` 的这一栏是**同一格会话** —— 同一份历史、同一套能力、同一排「模式」开关（在**任何一边**切都算数：AI 页切到 Agent，`Ctrl+K` 面板就是 Agent，反之亦然）。所以它**在 AI 页也照样能动手**：查资料类动作当场执行，记录里画成一行「用到动作：…」+ 一块结果；写入照旧给你一张**提议卡片**，点「应用」才落盘（点哪一边的卡片都算数）。左栏那条**主会话**是这两位共用的那一格，「角色 / 视角 / 主控」那几格则只演不动手。
- **它看得到什么**：面板顶上的「正在编」标签说明它此刻盯着哪一条。展开标题下面那行 **「这次带给模型的上下文」** 能看见实际喂进去的内容（当前世界、当前时间线前 12 个事件、时间指针年份、各类设定、以及你正在编那一条的字段与正文）。想让它看别的条目，就在左栏点一下那条再问。
- **它会记住**：对话与 AI 页的「主会话」是**同一份**，存在 `%APPDATA%\lingkuang\agent\sessions.json` 里那条 `role:'main'` 的记录上（最多留 120 条）；**长期记忆**存在 `%APPDATA%\lingkuang\agent\memory.json`（最多 60 条）。两个文件都能备份、能直接手改。（老版本的 `agent/chat.json` 只在首次升级时并进主会话一次，之后不再写。）
- **长期记忆（偏好）**：面板里那一栏「长期记忆」列出它记住的偏好，每条都能**就地改文字**、点 × 忘掉。两个来源：你自己「＋ 手动加一条」，或者点「从对话里总结」让它把最近的对话归纳成几条偏好 —— 总结来的那条左缘有一道强调色（`src=auto`）以示区别，重复的偏好不会被记第二遍。这些偏好在每次提问时都会带给模型（你展开「这次带给模型的上下文」看不到它，但它在系统提示里）。
- **它能做什么（动作）**：你可以直接使唤它，比如「建一条叫『雪原商队』的设定」「把银发少女的发色改成墨黑」「给这条事件补一句简述」。它内部是把这类请求转成**一条动作指令**（`{"tool":"…","args":{…}}`）——查资料类的动作（找设定、看事件列表、搜关键词）它**当场就查**，查完接着回答你。
- **它也能改灵框自己的设置**（2026-09-26 起，用户要求「给 AI 留一条改灵框设置的通道」）：你说「把写入改成不用问我」「切成只读」或者「你自己切到 Agent」，它会照做、或给你一张**提议卡片** —— ⭐ **放宽**权限那一步（切 Agent / 改成可写 / 关掉询问）**永远**要你亲手点「应用」，哪怕当前是「直接执行」档；**收窄**（切回聊天 / 改只读 / 改回每次询问）当场生效。
- **权限（两把旋钮，两个模式都可用）**：左边是**范围**，右边是**询问**，默认 **可写 + 每次确认**。权限是"允许它做到哪一步"的长期设定，模式只决定"这次要多自主" —— 所以聊天模式里也能改。
  - **只读**：只能查资料，改不了任何东西；想改也只给你「你可以这样改」的文字 —— ⭐ 只读**优先于**询问，哪怕右边选了「直接执行」也一个字都不许改。
  - **可写 + 每次确认**：它想改稿子会先给你一张**提议卡片**（写清「做什么、从什么改成什么」），你点 **应用** 才落盘；点 **忽略** 就什么都不做。**卡片出来之前，你的数据一点没动。**
  - **可写 + 直接执行**：它直接动手改（仍然进撤销栈，`Ctrl+Z` 能退）。
  - 卡片的按钮跟数据一样是即时生效的：应用完那张卡会标「已应用」并写明结果，忽略的标「已忽略」。
- **引擎**沿用设置里的那一套（见 §5「AI 引擎配置」）：**当前在用的那家供应商**与它选中的模型。

## 10. 常见问题（FAQ）

**Q：SmartScreen 提示"未知发布者"？**
A：未签名应用的正常提示，点「更多信息 → 仍要运行」。开源项目暂未购买代码签名证书。

**Q：联想图提示"联想不可用"？**
A：未配置 AI 引擎。要么装本地 Ollama（免费），要么在设置里填 API（见 §5）。核心功能不受影响。

**Q：词库的虚线/实线是什么意思？**
A：虚线 = 联想出的新词（不在词库，可暂存）；实线 = 已在词库。

**Q：数据会丢吗？**
A：数据在 `%APPDATA%\lingkuang\`，卸载/更新不删。担心可定期备份该目录。

**Q：剧情范围聚焦后看不到世界历史了？**
A：点 tl-manager「剧情」按钮切到「历史」（或下拉选「世界历史」）即可看全部；再点回聚焦。
