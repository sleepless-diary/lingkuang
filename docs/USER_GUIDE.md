# 灵框 LingKuang · 用户操作手册

阈限梦核世界观工作台：时间线 / 随机角色生成 / 词义联想图 / Markdown 编辑器。

---

## 1. 安装与启动

**普通用户**：从 [Releases](https://github.com/sleepless-diary/lingkuang/releases) 下载
- `LingKuang-x.x.x-x64.exe` — 安装版，双击安装
- `LingKuang-x.x.x-portable-x64.exe` — 便携版，双击即用

**开发者**：需 Node.js 18+，`npm install && npm start`

> 数据保存在系统 `%APPDATA%\lingkuang\`（时间线、设置、暂存词），卸载/换版本不丢失。

## 2. 界面总览

- **左侧导航栏**：工具 / 插件（世界观 · 设定库 · 灵感触发器）/ 系统
- **大厅**：插件卡片，点击进入各工具
- **AI 面板（The Hum）**：右下角呼吸灯，AI 对话入口（实验性）

## 3. 世界沙盘（时间线 + 地图）

### 浏览
| 操作 | 效果 |
|---|---|
| 拖拽空白 | 平移画布 |
| 滚轮 | 横向移动 |
| **Alt + 滚轮** | 缩放（以鼠标为中心） |
| Alt + 右键拖 | 快速缩放 |
| 右键 | 节点/画布菜单 |
| 点节点 | 右侧详情面板（标题/时间/描述/标签/关联人物地点） |

### 节点操作
- **添加**：右键空白 → 「添加节点」→ 填时间/类型/标题/描述
- **编辑**：点节点 → 右侧面板改内容
- **删除**：右键节点 → 「删除节点」
- **类型**：世界事件 / 剧情·人物 / 年代锚点 / 循环边界

### 多时间线
- 顶部 tabs 切换；「＋」新建时间线
- 「并列」：并排显示所有时间线（对齐时间轴）；「序列」：事件等距视图

### 循环（轮回）
- 右键 →「创建循环」→ 面板吸管吸取**起始/结束边界节点**（或填年份自动建）
- 循环次数 `count` 可设多轮——重复轮次自动渲染为**实节点**（内容与第一轮同步）
- 循环框可点选，右侧面板改循环名/起止/次数/删除
- 共享边界：起始年与已有循环结束年一致时自动复用为共享边界（菱形 + 黄环）

### 剧情范围（AE 工作区式）⭐
聚焦"故事发生的区间"，范围外的世界历史被裁剪：

1. **创建**：右键 →「创建剧情范围」→ 面板里点「◉ 吸取起始节点」→ 面板收起，鼠标变十字 → 点时间线上的节点 → 面板弹回显示已选 → 同样选**结束节点** → 命名 →「创建范围」
2. **聚焦**：创建后自动聚焦该范围——时间线只显示范围内的节点，世界历史裁掉；顶部荧光绿色带标注剧情区间
3. **切换**：
   - tl-manager「剧情」按钮：聚焦 ↔ 世界历史（全显示）
   - 下拉：多个范围间切换 / 「世界历史」
4. 一条时间线可建**多个剧情范围**（如"第一章""第二章"），它们同属一条时间线

### 多世界观
- 顶部世界观按钮 → 切换/新建世界观（互不干扰，各自独立时间线）

## 4. 灵感触发器（随机角色生成）

1. 进入「灵感触发器」→ 点「随机生成」
2. 每组卡片右上角 **select**：词条数（随机 / 1..4）
3. **锁定**：点词条右侧 `⚿` → 下次随机保留该词（绿色实底）
4. **保存组合**：输入名字 →「保存」→ 变成胶囊；点胶囊加载、× 删除
5. **词义联想入口**：点任意词条 → 底部联想图以该词展开

### 暂存与导出（扩充词库）
- 联想图里**虚线词**（未入库）点「存」暂存；**实线词**已在词库无需存
- 攒几个后点「**导出暂存词**」→ Ollama 自动分类 → 写入词库（之后生成/联想能抽到）

## 5. 词义联想图

**打开**：灵感触发器页点任意词条，或在联想图顶部输入框输词点「联想」。

| 操作 | 效果 |
|---|---|
| 点词（未展开） | 展开它的一级联想（5 个直接相关词，本地/API LLM 生成） |
| 再点焦点词 | 刷新它的联想（保留已选支线） |
| 点虚线词「存」 | 暂存到词库（导出时写入） |
| 拖动节点 | 子树跟随（组内力导向，与外部断开） |
| 拖拽空白 | 平移画布 |
| Alt + 滚轮 | 缩放画布 |
| 点「导出暂存词」 | 批量分类并写入词库 |

**选中支线**：点过的词变成**描边绿**（保留支线）——刷新/收起都不丢；**实底绿** = 已暂存。

### AI 引擎配置（设置 → 联想引擎）
| 模式 | 配置 | 成本 |
|---|---|---|
| 本地 Ollama | 装 Ollama + `ollama pull qwen2.5:7b` | 免费 |
| OpenAI 兼容 API | Base URL / API Key / 模型（如 DeepSeek：`https://api.deepseek.com/v1` + `deepseek-chat`） | 按量付费 |

未配置 AI 时，核心功能（时间线/生成/编辑器）完全可用，仅联想图不可用。

## 6. 设定库（工作台 · Markdown 编辑器）

> 「编辑器」工具已于 2026-09-13 并进**设定库**：**左栏是一棵文件夹树**
> （世界 → 时间线 → 种类 → 节点 ＋ 世界 → `_設定` → 类型 → 实体），跟硬盘上的目录一一对应，
> **打开就全部展开**（点某一枝收起）。没有别的形态、也没有筛选按钮 —— 要找哪一类就展开哪一枝。

- 左侧：**一个搜索框**（设定与事件一起搜，跨类别）+ **那棵树**
  —— 点左侧任意一行就编辑它（设定条目走中栏字段、时间线节点走属性面板 + 面包屑）
  - 树默认**全展开**；点「世界 / 时间线 / 种类 / `_設定` / 类型」这些行就是**收起／展开**那一枝
  - 没有节点的种类不列（硬盘上没这个文件夹）；实体类型**全部**列出来，空的置灰、展开会写一句「这个类型还没有实体」
- 中栏档案字段（模板决定有哪些字段）、右栏正文 = Markdown 所见即所得（失焦自动保存）
- 右上角那一组按钮**跟着你正在编的东西变**：
  - 编**设定条目**时：「类型 ▾ + 数量 + ＋新建实体」——**类型会跟着你正在编的那条走**（你改选别的类型，
    就以你选的为准，直到换条目）；**数量框**填 3 就是一次建 3 个，名字自动取唯一（新实体 / 新实体 2 / 新实体 3）
  - 编**时间线节点**时：「时间线 ▾ + 数量 + ＋新建节点」——**不用切去世界沙盘**，点一下就建一个（落在你选的那条时间线里，
    种类跟着你正在看的那个节点走），建完自动选中它（见 §3 世界沙盘时间线）
  - 刚建出来还没改名的条目在左树里是**绿色名字 + 一颗「待填」小药丸**（改过名就自动消失）——批量建完一眼看得出哪几条还没动
- 实体右边缘还有一条**演变**竖线（每个事件节点一版，见 §9）
- 编**时间线节点**时，中栏下方还有一块「**这件事改变了谁**」：这个事件改过哪些设定
  （名字 / 类型 / 第几版 / 改了什么），**点一行就跳到那条设定在这个事件之后的样子**
  —— 也就是"这件事发生之后，它长什么样"（`docs/BUGS.md` 第二十三轮）
- 正文上方两个小按钮：`H`（当前段落设为一级标题）／「插图」（把图片放进 vault 的 `assets` 并插到光标处）

## 7. 设置（左下角 ⚙ · **悬浮面板**）

点左栏最底下的「设置」，会浮出一层面板：**主区不动**（你正在编的条目、左栏展开的样子、滚动位置都留在后面），
改完点 × / Esc / 点面板外面就关掉。再点一次那个按钮也能关。

| 项 | 说明 |
|---|---|
| 缓动速度 / 缩放灵敏度 / 标尺密度 | 画布手感 |
| **联想引擎** | AI 模式 / Base URL / Key / 模型（见 §5） |
| **设定演变** | 改动什么时候变成"一版"（手动 / 自动 / 锁定），详见 §9 |
| **换条目转场** | 在设定库里点另一条条目时的过渡：开关 / 速度 / 行与行错峰 / 入场距离。改完立刻生效，点一下左边的条目就能看出区别；关掉＝瞬间切换 |

## 8. 数据与备份

- 数据目录：`%APPDATA%\lingkuang\`（`worldbuilding.json` 时间线 + `settings.json` 设置 + 暂存词在 localStorage）
- 备份：直接复制该目录即可；恢复：放回原路径
- 词库（`data/character_lib.json`）随应用分发，编辑 JSON 可自定义（58 个分类 key）

## 9. 常见问题（FAQ）

**Q：SmartScreen 提示"未知发布者"？**
A：未签名应用的正常提示，点「更多信息 → 仍要运行」。开源项目暂未购买代码签名证书。

**Q：联想图提示"联想不可用"？**
A：未配置 AI 引擎。要么装本地 Ollama（免费），要么在设置里填 API（见 §5）。核心功能不受影响。

**Q：词库的虚线/实线是什么意思？**
A：虚线 = 联想出的新词（不在词库，可暂存）；实线 = 已在词库。

**Q：数据会丢吗？**
A：数据在 `%APPDATA%\lingkuang\`，卸载/更新不删。担心可定期备份该目录。

**Q：剧情范围聚焦后看不到世界历史了？**
A：点 tl-manager「剧情」按钮切到「历史」（或下拉选「世界历史」）即可看全部；再点回聚焦。
