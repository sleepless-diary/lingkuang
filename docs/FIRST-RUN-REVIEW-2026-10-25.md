# 零基础第一次打开灵框（2026-10-25）· 实测找茬与优化方向

> 触发：用户要求「想象你是一个零基础的人，第一次打开灵框会怎么样，并据此找茬，找到优化方向」。
> 方法：**真跑**，不是读代码猜。用测试后门起隔离实例（`LINGKUANG_TEST_DATA` / `LINGKUANG_VAULT` /
> `LINGKUANG_TEST_USERDATA` 全部指向新建的空目录 = 真正的首次启动），CDP 逐个动作实测 + 截图 +
> 取 DOM 实测值；再对照源码定位根因。窗口 1440×900（另测 1366×700 笔记本尺寸）。
> 截图与脚本都在 `.review/firstrun/`（gitignore，本机留档），关键判断都附**可复现步骤**。

## 0. 一句话结论

**首屏是一张 93 个字的空白画布**（22 个控件、6 个是灰的、0 句"从哪开始"）。
新手唯一会坚定去点的按钮是右上角「＋节点」——**它在没有时间线时完全没反应**（不是报错，是静默 return）。
而灵框真正能带人上手的两个东西（会动手的助手、会出世界地图的生成器），一个藏在 `Ctrl+K` 后面
（全应用零提示、零菜单栏、零帮助入口），另一个被挤在 0 级界面的工具条里当第 4 个小按钮。

换句话说：**能力都在，主路径是断的。**

## 1. 我作为零基础用户走的 4 分钟（真实操作顺序）

| 时刻 | 我做了什么 | 发生了什么 |
|---|---|---|
| T+0 | 打开 | 全灰画布；时间线区域只有一句「无时间线 · 待建」；下半屏一张空白"地图"（一个灰盒子） |
| T+10s | 看到右上「＋节点」，点它 | **什么都没发生**：没有弹窗、没有提示、没有光标变化、数据文件不变 |
| T+20s | 猜 tab 栏那个裸「＋」是"新建" | 弹出「新建时间线」（默认名"新时间线"）→ 创建 → 尺子出来了，**但画布上「无时间线 · 待建」还挂在那儿** |
| T+40s | 再点「＋节点」 | 右侧 300px 表单：名字 / 年份 / 种类 / 模板字段（起因·影响）/ 导致 / 类型 / 描述 / 正文(Markdown) |
| T+70s | 只填名字「王城」→ 创建 | 时间线中央出现一个空心圆点 + 「王城」，右栏清空，焦点跑到 body（没有选中它、没有编辑入口提示） |
| T+90s | 左栏「设定库」 | 一棵树：5 个类型全是 0，每个下面一行"这个类型还没有实体"；中栏「左边选一个实体」；右栏「演变 · 起点/初稿/改这里」 |
| T+120s | 点右上「＋新建实体」 | 树里多出一行「新实体 · 待填 · 草稿」，中栏出现 11 个字段 + 200 字刻度 |
| T+150s | 想用自己的世界名：世界 tab「＋」→ 不改名直接创建 | 得到「新世界 2」并自动切过去 —— **可这个新世界没有任何"类型"** |
| T+160s | 在「新世界 2」里再点「＋新建实体」 | **毫无反应**（不是灰的，是能点但什么都不发生）。重启之后才恢复 |
| T+180s | 乱点「实验室」 | 发现 7 个工具（灵感触发器/AI/地图生成/素材库/结构体管理/回收站/备份） |
| T+200s | 无意中按到 `Ctrl+K`（没有任何提示告诉我） | 助手栏打开：模式/权限/步数/文件夹/长期记忆/上下文 6 组开关铺在对话之前 |
| T+220s | 问它「我是第一次用，想写一个奇幻世界，第一步该做什么？」 | **答得非常好**：一句话讲清"先建世界"，并给了一张可点的「新建世界：奇幻世界 → 应用」卡片 |
| T+240s | 点地图栏「生成地形…」 | 一张真地图 + 8 种画法 —— 全程唯一"上头"的时刻，也是我唯一想分享给他人的东西 |

**结论：新手在 T+200s 之前，唯一的"成就感"来自填完一张 8 字段表单换来的一个小圆点。**
最好的向导（助手）与最好的玩具（地图）都不在主路径上。

## 2. 硬伤（可复现，建议这一轮就修）

### B1 ★★★ 「＋节点」在空世界里静默失败
- **复现**：全新数据目录 → 首屏 → 点「＋节点」。无对话框、无 toast、无文案、数据不变。
- **根因**：`src/ui/timeline.ts` nodeBtn 处理 —— `const id = activeTimelineId(store); const tl = id ? … : undefined; if (!tl) return;`
  没有时间线就直接 return。
- **为什么严重**：这是首屏**唯一**一个看起来像"新建内容"的明确按钮；新手第一下就撞死在这里，且得不到任何解释。
- **建议**：`if (!tl) { 建一条默认时间线（或直接弹「先给这个世界建一条时间线」的小面板，带"就建一条，名为主线"一键）}`；
  同类入口「＋循环」「＋剧情线」在无时间线时**置灰并给 title 说明**，不要留成"能点但没用"。

### B2 ★★★ 建完第一条时间线，画布上还写着「无时间线 · 待建」
- **复现**：世界 0 条时间线 → 建第 1 条（空线）→ 尺子画出来了，左上角**同时**显示「无时间线 · 待建」。刷新后消失。
- **根因**：`timeline.ts` `renderBase()` 空分支把 `nodeSig = ''`；而有时间线但 0 节点时 `sig` 也等于 `''`
  ⇒ 下一次渲染走"结构没变，只挪 left"的快路径（`if (sig === nodeSig && nodeEls.size === nodes.length)`），
  `track.innerHTML` 永不替换，占位 div 就一直留着。
- **建议**：空分支写哨兵值（如 `nodeSig = '\u0000empty'`），或快路径加一条 `if (!track.querySelector('.tl-line')) 强制重建`。
- 这条还有个隐性代价：新手刚建完时间线看到"无时间线"，会以为**自己刚才那一步没成功**，于是再建一条。

### B3 ★★★ 新建世界观后，设定库「＋新建实体」点了没反应（要重启才好）
- **复现**：首启（默认世界有 5 个类型）→ 世界 tab「＋」→ 默认名创建 → 切到「新世界 2」→ 设定库 →
  头部「类型▾ / 数量」**整组消失**、树里 `_设定` 下**一个类型都没有** → 点「＋新建实体」无任何反应。
  刷新页面后：类型补齐（5 个），按钮立刻正常，并且能建出实体。
- **根因**：`src/store/actions.ts` 的 `addWorld()` 只写 `{ name, timelines:{}, order:[], docs:{} }`，
  **不写 `entityTypes`**；补默认类型的是 `ensureEntityTypes()`，而它只在启动加载时跑一次。
- **为什么严重**：这是新手"给自己世界起个名字"的必经动作，做完之后**当前世界在设定库里是死的**，
  而且没有任何提示指向"重启"。
- **建议**：`addWorld` 里直接复用 `ensureEntityTypes` / `ensureEntityFields` 的默认表（一份数据源），
  或在 codex 头对 `kinds.length === 0` 显示「这个世界还没有类型 · 去结构体管理加一个（按钮）」，
  并把「＋新建实体」置灰 + title 说明，别留成"能点但没用"。

### B4 ★★ 一个"空世界"在下次启动时会消失
- **复现**：首启（新世界，vault 里没有它的目录）→ 新建「新世界 2」（`addWorld` 会建 vault 目录）→
  刷新/重启 → 数据文件里只剩「新世界 2」，「新世界」不见了。
- **根因**：`src/main.ts` `loadData()` —— 只要 vault 扫到**任意**世界，就整体用 vault 结果替换 JSON 世界
  （`if (Object.keys(data.worldsets).length) return { data }`）；没有 vault 目录的世界不会被复活。
- **为什么对新手致命**：新手会先建一堆世界试手（就跟我一样），下次打开少了几个，**第一反应是"这软件会丢数据"**。
- **建议**：vault 替换时，把 JSON 里有、vault 里没有、且**内容为空**的世界保留（或在启动时保证每个世界都有目录：
  在 `createWindow` 之后对 `worldsets` 逐个 `vaultEnsureWorld`）。

### B5 ★★ 禁用控件仍然显示可点
- **实测**（首屏地图栏 3 个下拉）：`#map-contour` `disabled=true`，但 `cursor: pointer`、`opacity: 0.7`，
  颜色与旁边可用按钮几乎一致。新手会点、会再点、会以为是 bug。
- **建议**：`:disabled { cursor: not-allowed; opacity: .45 }`（一条 CSS），并给 `title` 写明"要先有地形"。

### B6 ★★ 文案把「实验室」里的工具说成"左栏"
5 处同源错误（都是"实验室抽屉"改版前的旧文案）：
- `codex.ts:1284` 头部：「字段由模板决定（在**左栏**「结构体管理」里改模板）」→ 实际在 **实验室 → 结构体管理**
- `codex.ts:1072` / `node-form.ts:212`：「到**左栏**「结构体管理」里加」→ 同上
- `node-form.ts:157`：「种类（模板 · 在**左栏**「结构体管理」里定义）」→ 同上
- `codex.ts:1555`：备份提示里的「**左栏**「备份管理」」→ 实际在 **实验室 → 备份管理**
- **为什么严重**：新手会真的去左栏找，找不到就以为功能不存在。**这是"用户按提示走，走不通"级别的错。**

### B7 ★ 空态文案指向一个禁用的按钮
`codex.ts` 演变栏空态：「还没有版本 / 选好事件，点下面的 ＋」，而下面那颗「＋ 记一帧」是 `disabled`。
建议：空态改成「这条设定还没有版本 · 先在上面的树里选一条设定」，或干脆把禁用态换成可点的引导（点了告诉你去哪选）。

### B8 ★ 世界 / 时间线**不能改名，删除只有右键**
- 实测：双击世界页签 → 无反应（没有就地编辑）；右键才有「删除世界观」；时间线同理。
- 新手几乎必然产出 `新世界 2`、`新时间线` 这类名字，然后**没有任何办法改回来**，只能删了重建（删也是右键）。
- **建议**：页签双击 = 就地改名（AI 会话列表已有这套实现，`ai-workbench.ts:293` 可复用）；
  右键菜单外露一个 `⋯` 按钮（悬停出现也行），别把唯一入口藏在右键里。

## 3. 设计缺口（不是 bug，但决定新手留不留）

### G1 首屏没有"下一步"
实测：可见文字 **93 个**、文本节点 25 个、控件 **22 个**（6 个禁用）、**0 句**"从这里开始"。
新手需要的是**一个动词**，不是 22 个名词。

### G2 高级概念在 0 级就上桌
首屏就摆着：`非线性`、`剧情线`、`＋剧情线`、`＋循环`、`无时间线 · 待建`、
地图栏 8 个控件（等高线/风格/立体/区域/标记/地形·手绘/移动/清空标记/平移）。
这些是**写了大半本书之后**才用得上的东西，却和"新建第一件事"平级。

### G3 同一件东西有三四个名字（新手要先学 6 组同义词）
| 说的是同一件事 | 界面上的叫法 |
|---|---|
| 一条设定 | 条目 / 实体 / 设定 / _設定 |
| 时间线上的东西 | 节点 / 事件 / 种类 / 类型 |
| 世界 | 世界 / 世界观 / 世界集 / 世界沙盘 |
| 版本 | 演变 / 帧 / 初稿 / 起点 |
| 视角 | 沙盘 / 时间线 / 全览 / 聚焦 |
| 剧情 | 剧情线 / 剧情范围 |
最刺眼的是**新建节点表单里同时有两个下拉搜"类型"**：「种类（模板）」和「类型（世界事件/剧情人物/年代锚点/循环边界）」，
两个都是必选、都长得一样，新手不可能知道区别。

### G4 唯一的"向导"藏在快捷键后面，而快捷键全应用零提示
- 应用**没有原生菜单**（`Menu.setApplicationMenu(null)`）：没有「帮助 / 关于 / 文档 / 打开数据目录」。
- `Ctrl+K`（助手）、`Ctrl+P`（命令面板）、`Ctrl+J`、`Alt+滚轮`、`右键`、`双击分割条` 全部**没有任何 UI 提示**。
- 而助手恰恰是本次实测中**唯一**能一句话回答"我该干什么"并在界面上**给出一张可点卡片**的东西。

### G5 右键是唯一入口
加节点（空白处右键）、删节点、复制节点、删世界、删时间线 —— 全靠右键。新手不右键。
（「＋节点」是例外，但它又撞上 B1。）

### G6 出厂没有"示例世界"
`data/worldbuilding.js` 里的种子世界观**存在但首启不加载**（`loadData()` 只读 JSON 与 vault）。
新手打开看到的是空世界；一个"示例世界（3 条时间线 / 十来个事件 / 几条设定）"能让他第一眼就明白
「世界 → 时间线 → 事件」「设定 → 类型 → 字段」这两条结构是怎么用的。

### G7 空态说了"做什么"，没说"怎么做"
- 设定库中栏：「左边选一个实体」——可是左边一个实体都没有；真正的动作在**右上角**（且只有它是绿的）。
- 左树 5 个类型各挂一行"这个类型还没有实体"＝ 5 行同样的噪音。
- 演变栏：「还没有版本 / 选好事件，点下面的 ＋」→ 那个 ＋ 是灰的（B7）。

### G8 新建节点表单对新手是"考试"
8 个输入：名字、年份、种类、种类模板字段(起因/影响)、导致、类型、描述、正文。
- 年份占位符 `312 或 312年7月 / 312年7月15日 / 312-7-15` —— 这是**格式暗号**，不是说明。
- 正文预填 `#事件：` + `节点正文…` 的 Markdown 模板 —— 新手不知道这是"可删的"。
- 「导致（箭头从新节点指向这些节点·可留空）」——这三个字本身就是世界观写作者的术语，不是软件术语。

### G9 助手栏的"默认状态"是给老手看的面板
打开就是一屏开关：模式（一轮/自动 + 步数不限/8/20/50）、权限（只读/可写 + 每次确认/直接执行）、
逐项确认说明、文件夹、长期记忆、上下文。**对话区在最后一屏之外**。
实测：新手问一句话，回答里还会出现 `create_world 函数`、`` `create_timeline` `` 这类内部词。

### G10 悬浮面板不随工具关闭
「地图生成」面板在切到「设定库」之后仍然浮在上面（实测跨 3 次工具切换没关）。
1366×700 下它直接盖住地图栏的「区域/标记/生成地形…」（面板 560px ≈ 屏宽 41%）。

## 4. 优化方向（按"目的"分三档，不是按代码量）

### 方向 A · 止血（半天，纯修 bug，不改设计）
1. 修 B1 / B2 / B3 / B4 / B5 / B6 / B7（每条都是 1–20 行）
2. 空态文案统一过一遍：所有 `disabled` 的按钮旁边不写"点它"
3. **验收**：
   - 全新数据目录 → 点「＋节点」→ 要么建出东西，要么弹一句人话（不许静默）
   - 全新数据目录 → 建时间线 → 画布上不再出现"无时间线"
   - 新建世界 → 设定库「＋新建实体」直接可用（不需要重启）
   - 建 2 个世界 → 重启 → 2 个都在
   - 首屏禁用控件 `cursor !== 'pointer'`
   - 全库 grep「左栏」→ 0 处指向实验室工具

### 方向 B · 首启引导（1–2 天，不改数据模型）
把「空白画布」换成**一条 3 步的路**，且每一步都能一键完成：
1. **你的世界叫什么**（默认「未命名世界」，就地输入）
2. **建第一条时间线**（默认「主线」，直接建好 —— 别让新手先学会"时间线"这个词才允许开工）
3. **写下第一件事**（预填好年份＝时间指针、种类＝事件，只要一个标题就能创建）

具体做法（低成本、可关掉）：
- 世界/时间线为空时，画布中央放一块 `.lk-empty`（**项目里已有这个原语**，2026-10-17 那轮做的）：
  一句目的 + 一个主按钮 + 一行"或者，先看看示例世界"。
- **示例世界可选加载**：把 `data/worldbuilding.js` 变成"新建世界时勾选『带示例内容』"或首启的第二个按钮。
  这是最省力的引导：让人**看到**结构，而不是读解释。
- 引导**不做**多步弹窗教学（见第 5 节），只做空态卡片。

### 方向 C · 结构性调整（要设计决定）
1. **术语收敛**（影响最大、最便宜）：定一套名字写进 `docs/DESIGN.md`，界面一律照抄 ——
   建议：世界 / 时间线 / 事件 / 设定 / 类型 / 版本。把「条目·实体·世界集·帧·初稿·种类」从**用户可见文案**里清掉。
   新建节点表单里那两个"类型"下拉必须改名（种类→「事件种类」，类型→「沙盘画法」或直接并进种类）。
2. **右键之外的第二入口**：树行/页签悬停出 `⋯`，菜单项与右键同源（一个函数两处挂）。
3. **常在的帮助位**：左栏底部「设置」旁边加「?」，里放 3 条快捷键 + 「打开使用手册」+ 「打开数据目录」+「关于」。
   （没有原生菜单，这一格就是唯一稳定入口；手册就指 `docs/USER_GUIDE.md` 的 GitHub 链接。）
4. **助手前置**：首屏空态卡片里放一颗「问问助手」（等价于 `Ctrl+K`，并**主动注入一句开场**：
   "这是我第一次用，帮我规划第一小时的步骤"）。助手已经能给出可点卡片，缺的只是入口。
5. **从"空白"到"有东西"的最短路径**：把「生成地形…」提到首屏空态里当第二个 CTA
   （它是唯一一个 30 秒内能产出"哇"的东西，适合做留存钩子）。

## 5. 明确**不要**做的
- **不要**做多步弹窗教学（高亮一个点下一步那种）：本项目的气质是"工具不像教程"，且新手关掉就再也找不到。
  空态卡片 + 示例世界足够。
- **不要**为了新手把高级功能藏起来或加二级菜单：`非线性/循环/剧情范围` 已经是老手的主路径，
  本轮只要求它们**在 0 级不抢位置**（视觉降级 / 折进 `⋯`），不是删。
- **不要**改数据模型来"顺手"解决 B3/B4：都是补一行初始化 / 一条保留规则的活，动模型风险远大于收益。

## 6. 附：本次实测的量化底数（可作回归基线）

| 指标 | 首启实测 |
