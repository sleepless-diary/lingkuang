## 4. 环境与纪律（踩过的坑，别重踩）

- **CRLF 陷阱**：`src/ui/timeline.ts`、`src/ui/shell.ts`、`main.js`、`preload.js`、`src/style.css`、`src/tools/*.ts` 是 **CRLF**。用 node 脚本打补丁时，多行 `old` 字符串里的 `\n` **匹配不到**（`n=0` 静默失败）—— 必须用 `/\r?\n/` 正则，或只做单行替换。`edit` 工具按行匹配、不受影响；但它要求"文件自上次读取后没被改过"。
- **三道检查**：`node --check main.js` → `npx tsc --noEmit` → `npx vite build`；然后重启正式应用。
- **e2e**：`tools/e2e/timeline-scale.cjs`（12 项，★4 已知遗留）。跑法：同一个 pwsh 里设 `LINGKUANG_TEST_DATA`/`LINGKUANG_VAULT`/`LINGKUANG_TEST_USERDATA` 指向 `%TEMP%\lk-evault2` → `node tools/e2e/reset-entity-vault.cjs` + `seed-node.cjs` → `Start-Process electron.exe -ArgumentList @($repo,'--remote-debugging-port=9346')` → 轮询 `/json/version` → `LK_CDP_PORT=9346` 跑套件。**动画类断言要轮询到稳定**（`stableTicks`）。
- **push 需代理**：`git config http.proxy = http://127.0.0.1:7892`（mihomo/Clash，端口见 KB `tech-notes/dev/proxy-mihomo.md`）；代理没开时 `Failed to connect to github.com port 443 via 127.0.0.1`。
- **测试实例**只按 `--remote-debugging-port` 匹配 CommandLine 杀，别广谱匹配（会误杀用户正式应用）。
- **方法论**：新断言必须先在**修复前**的代码上跑出 FAIL（否则是假绿）；判断"是不是我的回归"用 A/B（`git stash push -- src/` → 重建 → 复跑 → `git stash pop`）。
