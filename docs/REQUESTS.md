## 2026-10-31 · 第十七点十四分 · 液化 / 变换工具修改意见（原文，已实现）

用户原话（一字未改）：

> 液化里面的收缩和扩张只有在笔刷移动时才生效，还有笔刷的大小范围太小了，笔刷的推动在缓慢移动的情况下无作用，再加一个粘性系数的属性，再给工具的属性栏单开一行，变换工具在变换过程中也会更新变换窗口，导致变换时轴心也会变，就会导致很多奇怪的bug，还有我希望这整张图是左右贯通的，但是上下不贯通，上下改成超出范围的映射到对应位置，毕竟我们这是一个星球

拆成七条：

| # | 诉求 | 落点 |
|---|------|------|
| 1 | 收缩 / 膨胀按住不动也要一直生效 | 液化改成**逐帧连续**（位移场 + rAF），不再"只有 pointermove 才动" |
| 2 | 笔刷大小范围太小 | 1..40 → **1..160** 格（`[` `]` 同步） |
| 3 | 推挤在缓慢移动时无作用 | 位移累加进**浮点位移场**（以前 <半格被 `Math.round` 舍成 0） |
| 4 | 加粘性系数 | 新属性「粘性 0..8」：高 = 只有笔心带得动、整体更慢；低 = 像水整片跟着走 |
| 5 | 工具属性栏单开一行 | 顶栏的笔刷/强度搬进新的 `.lk-ed__tools` 行，液化再挂粘性 + 三键 |
| 6 | 变换时轴心跟着变 | 变换框与**轴心在按下时冻结**，拖动中不再重算包围盒；松手才重算 |
| 7 | 整图左右贯通、上下不贯通 | 采样与落笔：横向**取模环绕**（经度）；纵向**跨极点**——越过极点换到**对面经线**（x+半屏）+ 高度镜像 + 方向相反（球面口径 A，2026-10-31 17:35 追问后确认） |
